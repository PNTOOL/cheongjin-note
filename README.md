# 청진노트 · 간호학 시험공부 앱 (4차 업데이트)

틈날 때마다 열어서 **이어서 공부하기**만 누르면 되는 간호학 시험공부 앱입니다.
복습 시기와 순서는 앱이 정하고, 하던 곳은 자동으로 저장돼요.

지금 들어 있는 과목: **건강사정 7단원**
- 개념 108개 (기존 89개 + **추가 19개**), 모든 개념에 머리글자 → 뜻 연결이 보이는 암기법
- 문제 429개: 객관식 321개(국시형 255개 포함) + O/X 108개
- 빈칸 표 16개, 순서 맞추기 12개, 헷갈리는 쌍 42개, 숫자 기준값 44개
- 모든 개념에 **시험 중요도 ★**: ★★★ 자주 출제 31개 · ★★ 중요 53개 · ★ 기본 24개
  (국시·학교 시험에 자주 나오는 주제를 바탕으로 정한 값이고 공식 통계는 아니에요. 앱에서 직접 바꿀 수 있어요.)

## 4차에서 달라진 점

- **공부 모드**: 과목마다 고를 수 있어요 (첫 화면 과목 카드, 공부 탭).
  - **당일치기**: ★★★만. 하루 안에 몰아서 복습 (배운 직후 → 10분 → 1시간 → 3시간 → 다음 날 아침). 남은 개념 수와 걸릴 시간, ★★★ 요약지와 문제 테스트.
  - **핵심**: ★★ 이상, 중요한 것부터, 날짜 간격 복습.
  - **전체**: 모든 개념, 날짜 간격 복습 (새 개념 순서는 목차 순 또는 중요한 것 먼저).
  - 모드를 바꿔도 기록은 이어져요. 당일치기로 ★★★를 끝내고 전체로 바꾸면 나머지부터 나와요.
- **추가 내용 같이/빼고 공부**: 나중에 더한 내용(‘추가’ 표시)을 빼고 공부할 수 있어요.
- **고치고 보태기** (모두 이 기기에 저장)
  - 개념: 제목, **중요도 ★**, 설명, 요약, 암기 요령, 보완 메모 (개념 카드의 연필 버튼)
  - 문제: 정답·보기·해설 고치기, 이상한 문제 빼기 (문제를 푼 뒤 해설 아래 ‘문제가 이상해요?’)
  - **내 개념 추가**: 단원 화면이나 진도 → 고친 내용에서. 새 개념 순서, 복습, 목차, 암기노트에 들어가요.
- **모두에게 반영하기**: 진도 → **고친 내용 · 내 개념**
  1. 친구들이 **고친 내용 보내기**로 카카오톡에 파일을 보내요.
  2. 받은 사람이 **받은 고친 내용 합치기**로 합쳐요.
  3. **반영 파일 만들기**로 `subjects/과목id-fix.js` 파일을 받아 GitHub의 `subjects` 폴더에 올리면 모든 사람의 앱에 반영돼요.
- **과목 추가가 쉬워졌어요**: 과목 파일 + `list.js` 한 줄. `sw.js`는 고칠 필요가 없어요. 과목 파일은 그 과목에 들어갈 때만 불러와서 과목이 많아져도 느려지지 않아요.
- **첫 화면**: 학기별로 묶어 보여 주고, **과목 고르기**로 내가 듣는 과목만 보이게 할 수 있어요.

## 파일 구성

| 파일 | 역할 | 고칠 일이 있나요? |
| --- | --- | --- |
| `index.html` | 화면 모양 (모든 과목 공통) | 거의 없음 |
| `app.js` | 앱 동작 (모든 과목 공통) | 기능을 바꿀 때만 |
| `subjects/list.js` | 과목 목록 | 과목을 추가할 때 한 줄 |
| `subjects/health-assessment.js` | 건강사정 개념·암기법·기본 문제 | 내용을 고칠 때 |
| `subjects/health-assessment-q1.js` ~ `q4.js` | 건강사정 국시형 문제 (q4 = 추가된 개념의 문제) | 문제를 고칠 때 |
| `subjects/_template.js` | 새 과목 양식 (예시, 앱에는 안 나와요) | 새 과목을 만들 때 복사 |
| `subjects/과목id-fix.js` | 앱에서 만든 반영 파일 (있을 때만) | 앱에서 다시 만들어 올리기 |
| `manifest.json`, `icon-192.png`, `icon-512.png` | 폰에 앱으로 설치할 때 이름과 아이콘 | 거의 없음 |
| `sw.js` | 인터넷 없이도 열리게 하는 오프라인 저장 | 없음 |

## 4차 업데이트 올리기 (3차 버전을 쓰고 있다면)

바뀐 파일: `index.html`, `app.js`, `sw.js`, `README.md`, `subjects/list.js`, 새 파일 `subjects/_template.js`.
폴더째 모두 올려도 괜찮아요. 학습 기록은 그대로 남아요.

1. GitHub 저장소(`cheongjin-note`)를 열어요.
2. **Add file → Upload files**를 누르고, 압축을 푼 폴더 안의 파일과 `subjects` 폴더를 모두 끌어다 놓아요. 같은 이름의 파일은 새 파일로 바뀌어요.
3. **Commit changes**를 눌러요.
4. 1~2분 뒤 폰에서 앱을 껐다 켜면 새 버전이 열려요. (안 바뀌면 한 번 더 껐다 켜거나 새로고침)

> 혹시 모르니 바꾸기 전에 **진도 → 기록 백업**에서 백업 파일을 저장해 두세요. 1차·2차·3차 백업도 불러올 수 있어요.

## 처음 설치하기

1. GitHub에서 새 저장소를 만들어요 (예: `cheongjin-note`, Public).
2. **Add file → Upload files**로 이 폴더의 파일을 모두 올려요.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하고 Save.
4. 1~2분 뒤 `https://내아이디.github.io/cheongjin-note/` 주소가 생겨요.
5. 폰에서 그 주소를 열고 설치해요.
   - **안드로이드 (크롬)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
   - **아이폰 (사파리)**: 공유 버튼 → **홈 화면에 추가**

## 쓰는 법 한눈에

- **첫 화면**: 학기별 과목 카드 (진도, 정답률, 공부 모드, 추가 내용 같이/빼고, 이어서 공부).
- **공부**: ‘이어서 공부하기’ = 짧은 한 세트 (복습 → 새 개념 → 바로 확인 → 섞어 풀기). 평소 복습 간격은 배운 직후 → 같은 날 → 1일 → 3일 → 7일 → 14일 → 30일.
- **목차에서 골라 공부하기**: 단원·개념마다 중요도, 배움 상태, 정답률. ‘★★★ 자주 출제’, ‘★★ 이상’, ‘추가된 내용’, ‘내 개념’, ‘안 배운 것’, ‘약한 것’을 한 번에 고를 수 있어요. 지금 모드의 범위 밖 개념은 흐리게 보이지만 골라서 공부할 수 있어요.
- **암기노트**: A4 4단 요약지. 범위(전체·★★★만·★★ 이상·배운 것만·약한 것만)를 고르고 **PDF로 저장·보내기**. PDF는 처음 한 번 인터넷이 필요해요.
- **문제**: 관련 개념을 모두 배우면 열려요. 공부 모드 범위의 문제만 나와요. 틀렸거나 애매했거나 힌트를 본 문제는 다시 나오고, 2번 연속 깔끔하게 맞히면 졸업해요.
- **진도**: 단원별 진도·정답률, 약점 TOP 3, 착각 목록, 시험 기록, 그림 연습, 고친 내용, 설정, 백업.

## 과목 추가하기

1. `subjects/_template.js`를 복사해 새 과목 파일을 만들어요 (예: `subjects/pathophysiology-1.js`). 양식이 정해져 있어서, 목차나 강의 주제를 Claude에게 주고 파일을 만들어 달라고 하는 게 가장 쉬워요.
2. 그 파일을 GitHub의 `subjects` 폴더에 올려요.
3. `subjects/list.js`를 열어 연필(✏️)을 누르고, 앞 과목의 `}` 뒤에 쉼표를 붙인 다음 아래처럼 한 덩어리를 추가해요.

```js
  {
    id: 'pathophysiology-1',
    title: '병태생리학1',
    term: '1-2',
    kind: '전공기초',
    files: ['subjects/pathophysiology-1.js']
  }
```

4. **Commit changes**. 1~2분 뒤 앱 첫 화면에 과목이 생겨요.

- `id`는 과목 파일 안의 `NSA.subject({ id: ... })`와 똑같아야 해요.
- 파일 이름이 틀리거나 형식 오류가 있으면 첫 화면에 알림이 뜨고, 다른 과목은 그대로 쓸 수 있어요. GitHub의 **History**에서 이전 버전으로 되돌릴 수 있어요.

## 내 그림

- 그림이 도움이 되는 개념을 처음 배우면 ‘그림 넣기’ 안내가 한 번 나와요 (구글에서 찾기 · 사진 찍기 · 갤러리 · 나중에).
- 큰 사진은 긴 쪽 1600픽셀로 줄여서 저장해요 (고화질 2400). 사진의 위치 정보 같은 정보는 지워져요.
- 그림 위에 **번호 찍기** → 글자 **가리기** → ‘턱밑은 몇 번?’ 같은 위치 문제로 연습해요.
- 그림은 이 기기에만 저장돼요. 폰을 바꿀 때는 백업 화면의 **기록 + 그림 저장**을 쓰세요.

## 국시 기출

- 국시원 누리집 → 시험정보 → 출제자료(기출문제)에서 PDF를 받아, 글자를 복사해서 **문제 → 국시 기출 → 기출 붙여넣기**에 붙여넣어요. 정답표도 같이 붙여넣어요.
- 문항마다 과목(교시와 번호로 짐작)과 관련 개념이 자동으로 연결되고, 확인 화면에서 고칠 수 있어요.
- **기출문제는 저작권이 있어요. 이 기기에만 저장되고 GitHub에는 올라가지 않아요. 반영 파일에도 넣지 마세요.**

## 기록과 백업

- 학습 기록, 고친 내용, 내 개념은 **그 폰의 브라우저 안에만** 저장돼요. 브라우저 데이터를 지우거나 폰을 바꾸면 사라져요.
- **진도 → 기록 백업**에서 일주일에 한 번 백업 파일을 저장하세요.
- 아이폰은 사파리에서 연 앱과 홈 화면에 설치한 앱의 기록이 따로예요. 한 곳에서만 쓰세요.
