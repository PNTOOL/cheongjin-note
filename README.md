# 청진노트 · 간호학 시험공부 앱 (2차 버전)

틈날 때마다 열어서 **이어서 공부하기**만 누르면 되는 간호학 시험공부 앱입니다.
복습 시기와 순서는 앱이 정하고, 하던 곳은 자동으로 저장돼요.

지금 들어 있는 과목: **건강사정 7단원**
- 개념 89개 (1차 73개 + 새 개념 16개), 모든 개념에 머리글자 → 뜻 연결이 보이는 암기법
- 문제 359개: 객관식 270개(국시형 204개 포함) + O/X 89개
- 빈칸 표 12개, 순서 맞추기 10개, 헷갈리는 쌍 30개, 숫자 기준값 31개

## 파일 구성

| 파일 | 역할 | 고칠 일이 있나요? |
| --- | --- | --- |
| `index.html` | 화면 모양 (모든 과목 공통) | 거의 없음 |
| `app.js` | 앱 동작 (모든 과목 공통) | 기능을 바꿀 때만 |
| `subjects/list.js` | 과목 목록 | 과목을 추가할 때 |
| `subjects/health-assessment.js` | 건강사정 개념·암기법·기본 문제 | 내용을 고칠 때 |
| `subjects/health-assessment-q1.js` ~ `q3.js` | 건강사정 국시형 문제 | 문제를 고칠 때 |
| `manifest.json`, `icon-192.png`, `icon-512.png` | 폰에 앱으로 설치할 때 이름과 아이콘 | 거의 없음 |
| `sw.js` | 인터넷 없이도 열리게 하는 오프라인 저장 | 파일을 추가할 때 |

## 1차 버전에서 바꾸기 (GitHub에 다시 올리기)

1. GitHub 저장소(`cheongjin-note`)를 열어요.
2. **Add file → Upload files**를 누르고, 이 폴더의 파일을 **모두** 끌어다 놓아요. `subjects` 폴더도 폴더째 끌어다 놓아요.
   - 같은 이름의 파일은 새 파일로 바뀌어요. `app.js`, `subjects/list.js`, `subjects/health-assessment-q1~q3.js`는 새로 생기는 파일이에요.
3. 아래 **Commit changes**를 눌러요.
4. 1~2분 뒤 폰에서 앱을 껐다 켜면 새 버전이 열려요. (안 바뀌면 한 번 더 껐다 켜거나 새로고침)
5. **1차 버전의 학습 기록은 자동으로 옮겨져요.** 처음 열면 ‘새 내용이 추가됐어요’ 알림이 나와요.

> 혹시 모르니 바꾸기 전에 1차 앱의 **진도 → 기록 백업**에서 백업 파일을 저장해 두세요. 2차 앱의 백업 화면에서 1차 백업도 불러올 수 있어요.

## 처음 설치하기

1. GitHub에서 새 저장소를 만들어요 (예: `cheongjin-note`, Public).
2. **Add file → Upload files**로 이 폴더의 파일을 모두 올려요.
3. **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하고 Save.
4. 1~2분 뒤 `https://내아이디.github.io/cheongjin-note/` 주소가 생겨요.
5. 폰에서 그 주소를 열고 설치해요.
   - **안드로이드 (크롬)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
   - **아이폰 (사파리)**: 공유 버튼 → **홈 화면에 추가**

## 쓰는 법 한눈에

- **첫 화면**: 과목 버튼 (진도 %, 정답률 %, 이어서 공부). 마지막에 공부한 과목이 맨 위에 와요.
- **공부**: ‘이어서 공부하기’ = 약 5분짜리 한 세트 (복습 → 새 개념 2~3개 → 바로 확인 → 섞어 풀기). 복습 간격은 배운 직후 → 같은 날 → 1일 → 3일 → 7일 → 14일 → 30일.
- **암기노트**: 과목 전체를 A4 4단 요약지로 (암기용만 약 2쪽). 범위(전체·배운 것만·약한 것만)를 고르고 **PDF로 저장·보내기**로 카카오톡이나 메일로 보낼 수 있어요. PDF는 처음 한 번 인터넷이 필요해요.
- **문제**: 관련 개념을 모두 배우면 문제가 열려요. 풀기 전 ‘필요한 내용 보기’, 푼 뒤 ‘문제 해석’(묻는 것, 정답 이유, 보기별 해설). 틀렸거나 애매했거나 힌트를 본 문제는 다시 나오고, 2번 연속 깔끔하게 맞히면 졸업해요.
- **진도**: 단원별 진도·정답률, 약점 TOP 3, 착각 목록, 시험 기록, 그림 연습, 전체 내용 미리 보기, 설정, 백업.
- 모든 화면 왼쪽 위의 **← 이전** 버튼, 폰의 뒤로 가기 버튼으로 이전 화면으로 가요.

## 내 그림

- 그림이 도움이 되는 개념을 처음 배우면 ‘그림 넣기’ 안내가 한 번 나와요 (구글에서 찾기 · 사진 찍기 · 갤러리 · 나중에).
- 큰 사진은 긴 쪽 1600픽셀로 줄여서 저장해요 (고화질 2400). 사진의 위치 정보 같은 정보는 지워져요.
- 그림 위에 **번호 찍기** → 글자 **가리기** → ‘턱밑은 몇 번?’ 같은 위치 문제로 연습해요.
- 그림은 이 기기에만 저장돼요. 폰을 바꿀 때는 백업 화면의 **기록 + 그림 저장**을 쓰세요.

## 국시 기출

- 국시원 누리집 → 시험정보 → 출제자료(기출문제)에서 PDF를 받아, 글자를 복사해서 **문제 → 국시 기출 → 기출 붙여넣기**에 붙여넣어요. 정답표도 같이 붙여넣어요.
- 문항마다 과목(교시와 번호로 짐작)과 관련 개념이 자동으로 연결되고, 확인 화면에서 고칠 수 있어요.
- **기출문제는 저작권이 있어요. 이 기기에만 저장되고 GitHub에는 올라가지 않아요. 다른 사람과 공유하지 마세요.**

## 기록과 백업

- 학습 기록은 **그 폰의 브라우저 안에만** 저장돼요. 브라우저 데이터를 지우거나 폰을 바꾸면 사라져요.
- **진도 → 기록 백업**에서 일주일에 한 번 백업 파일을 저장하세요.
- 아이폰은 사파리에서 연 앱과 홈 화면에 설치한 앱의 기록이 따로예요. 한 곳에서만 쓰세요.

## 내용 고치기 · 과목 추가

- 앱 안에서: 개념 카드의 **수정(연필)** 버튼, **내 암기법 만들기**, **확인 필요(깃발)** 표시. 이 기기에만 저장돼요.
- 파일에서: `subjects/health-assessment.js`를 GitHub에서 열고 연필(✏️) 버튼으로 고친 뒤 Commit. 개념 `id`(예: `u5c07`)는 바꾸지 마세요. 내용이 바뀐 개념은 앱이 알아서 다시 복습에 넣어요.
- 다른 과목: `subjects/health-assessment.js` 형식으로 새 파일을 만들고 `subjects/list.js`에 한 줄 추가하면 첫 화면에 과목 버튼이 생겨요. `sw.js`의 파일 목록에도 추가하고 CACHE 숫자를 올려 주세요.
- 교수님 자료와 다른 부분은 깃발로 표시해 두었다가 비교하세요. 교수님 자료도 저작권이 있으니 공개 저장소에는 올리지 마세요.
