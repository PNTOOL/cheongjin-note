# 청진노트 · 간호학 시험공부 앱

매일 **오늘 공부 시작** 버튼만 누르면, 앱이 복습 시기와 순서를 정해 주는 간호학 시험공부 앱입니다.
1차 버전에는 **건강사정 7단원** (개념 73개, 문제 139개, 빈칸 표 10개, 순서 맞추기 8개)이 들어 있습니다.

## 파일 구성

| 파일 | 역할 | 고칠 일이 있나요? |
| --- | --- | --- |
| `index.html` | 앱 화면과 기능 (모든 과목 공통) | 기능을 바꿀 때만 |
| `subjects/health-assessment.js` | 건강사정 학습 내용 | 내용을 고치거나 문제를 추가할 때 |
| `manifest.json`, `icon-192.png`, `icon-512.png` | 폰에 앱으로 설치할 때 이름과 아이콘 | 거의 없음 |
| `sw.js` | 인터넷 없이도 열리게 하는 오프라인 저장 | 파일을 추가할 때 |

## GitHub에 올려서 폰에 설치하기

1. GitHub에서 새 저장소를 만듭니다 (예: `cheongjin-note`, Public).
2. **Add file → Upload files**로 이 폴더의 파일을 모두 올립니다. `subjects` 폴더도 폴더째 끌어다 놓으세요.
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하고 Save.
4. 1~2분 뒤 `https://내아이디.github.io/cheongjin-note/` 주소가 생깁니다.
5. 폰에서 그 주소를 엽니다.
   - **안드로이드 (크롬)**: 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**
   - **아이폰 (사파리)**: 공유 버튼 → **홈 화면에 추가**
6. 홈 화면의 청진노트 아이콘으로 열면 앱처럼 전체 화면으로 실행되고, 한 번 연 뒤에는 인터넷 없이도 열립니다.

> index.html 파일을 폰에 직접 다운로드해서 여는 방식은 설치가 안 되고 기록 저장도 불안정해서 권하지 않습니다.

## 수정하고 다시 올리기

- GitHub에서 파일을 열고 연필(✏️) 버튼으로 고친 뒤 **Commit changes**를 누르면 됩니다.
- 폰에서는 앱을 껐다 켜거나 새로고침하면 새 버전이 반영됩니다. 학습 기록은 그대로 남습니다.
- 개념 `id`(예: `u5c07`)는 바꾸지 마세요. 학습 기록이 id로 저장됩니다.

## 기록과 백업

- 학습 기록은 **그 폰의 브라우저 안에만** 저장됩니다. 브라우저 데이터를 지우거나 폰을 바꾸면 사라집니다.
- 앱의 **진도 → 기록 백업**에서 일주일에 한 번 백업 파일을 저장하세요.
- 새 폰에서는 같은 화면의 **불러오기**로 복원합니다.

## 교수님 자료 · 기출문제

- 교수님 자료와 다른 내용은 앱 안의 개념 카드 **수정(연필)** 버튼으로 바로 고칠 수 있습니다. 원래 내용으로 되돌리기도 됩니다.
- 의심 가는 내용은 **깃발(확인 필요)** 로 표시해 두고, 자료를 받으면 진도 → 확인 필요 목록부터 비교하세요.
- 학교 기출이나 국시원 공개 기출은 **문제 → 내가 넣은 문제**에서 입력하거나 붙여넣을 수 있습니다. 이 문제들은 내 폰에만 저장됩니다.
- 교수님 자료와 기출문제는 저작권이 있으니 **공개 저장소(GitHub Pages)에 올리지 마세요.**
